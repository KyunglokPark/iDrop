EUC-KR 서버의 한글 파일명이 깨지지 않게
!기존 FTP 클라이언트의 문제
많은 FTP 클라이언트가 파일 이름을 UTF-8로만 다뤄, EUC-KR(CP949)로 저장된 한글 파일·폴더 이름이 ???나 깨진 글자로 보이고 다운로드·업로드가 실패합니다.
✓iDrop의 해결
서버가 준 이름 바이트를 그대로 받아 자동 감지(UTF-8/EUC-KR)로 해석하고, 새 이름은 서버 인코딩으로 다시 만들어 보냅니다. 한 폴더에 두 인코딩이 섞여도 정상 표시됩니다.
서버 바이트 → iDrop 자동 감지(EUC-KR / UTF-8) → 화면 · 전송
